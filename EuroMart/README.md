## 🔍 Overview

Welcome to the **EuroMart Sales Analysis** project — a complete deep-dive into sales, profits, customer behavior, and product performance.  
This project was built using **Python**, **Pandas**, and **Data Visualization** libraries inside a Jupyter Notebook.

📁 *Notebook Used:* `EuroMart.ipynb`

---

## 🗂️ Project Highlights

### ✔️ Data Cleaning  
- Handled null values  
- Removed duplicates  
- Standardized columns  

### ✔️ Exploratory Data Analysis  
- Sales & Profit Distribution  
- Region-wise performance  
- Category & Sub-category insights  
- Customer segmentation  

### ✔️ Visualizations  
- Heatmaps  
- Bar & Line Charts  
- Trend Analysis  
- Profitability Plots
